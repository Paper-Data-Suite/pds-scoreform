# Issue #227 — Hardening B: durable create-only assignment creation

Scope: new `assignment.json` creation only. Existing assignment edits continue to use the independently reviewed staged-replacement path (`assignment_bulk_mutation`). No schema, Core API, reader contract, or release version change.

The former new-file writer opened the final assignment path in `w` mode and could leave truncated JSON after an interruption. The replacement stages a deterministic UTF-8 JSON candidate in the existing managed work directory, flushes and `fsync`s the complete bytes, reloads them through ScoreForm's strict native assignment decoder, checks the managed work identity and path ancestry, and installs with `os.link` (same-directory hard-link create-only). A competing existing filename makes that operation fail without replacement. The staging link is removed afterward. There is deliberately **no unsafe fallback** to `os.rename` (which may replace on POSIX), `os.replace`, or direct `O_EXCL` writes into the canonical destination. Unsupported hard-link filesystems fail closed rather than producing a half-written assignment.

Known limits: a filesystem must implement same-directory hard links; a network/sync provider may reject them. Directory ancestry is validated at preflight and immediately before installation, but unrelated processes that replace ancestor directories without coordinating cannot be made safe through portable pathname APIs alone. An ambiguous post-install error preserves the complete target and asks for inspection; it does not delete a possible successful commit. Staging cleanup after an abnormal process termination can leave only an uncommitted `.assignment.json.*.tmp`, never a partial canonical assignment. Do not delete unknown temporary files automatically.

Qualification: `tests/test_issue227_hardening_b_assignment_creation.py`, `tests/test_assignment_creation_storage.py`, existing assignment tests, Ruff, mypy, release compatibility, then final full suite and cross-platform release gates. Run installed-wheel acceptance before release.
